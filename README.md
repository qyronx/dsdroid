# DSDroid — 닌텐도 DS 에뮬레이터 앱 (Drastic 스타일)

- 내 롬(.nds) 불러오기 / 게임 실행 (DeSmuME libretro 코어 + LibretroDroid)
- **게임 데이터(SRAM, 인게임 저장)** 와 **진행 상황(세이브 스테이트 슬롯 1~4 + 자동 이어하기)** 을 별도로 저장
- 세로/가로 모드 지원, DS 스타일 가상 패드(십자키, A/B/X/Y, L/R, START/SELECT, 메뉴)
- `usercheat.dat`(R4/DeSmuME 형식) 불러오기 + 게임별 치트 선택/적용
- 전체 백업(zip) → 다른 폰에 앱 설치 후 복원하면 이어서 플레이
- 블루투스/USB 게임패드 지원

## GitHub Actions 로 APK 만들기
1. 이 폴더 전체를 GitHub 저장소에 push (브랜치 `main`).
2. 저장소 **Actions** 탭 → `Build APK` 실행 (push 하면 자동 실행).
3. 완료 후 실행 결과 하단 **Artifacts → DSDroid-apk** 에서 `DSDroid.apk` 다운로드.
   - `v1.0` 같은 태그(`git tag v1.0 && git push --tags`)를 push 하면 Releases 에도 APK 가 첨부됩니다.
4. 폰에서 APK 설치 (출처를 알 수 없는 앱 허용 필요).

워크플로가 하는 일: 코어(`desmume_libretro_android.so`)를 libretro 빌드봇에서 내려받아 `jniLibs` 에 넣고 → `gradle assembleRelease`.
(릴리스 빌드(debuggable 아님)를 debug 키로 서명하므로 바로 설치 가능. 스토어 배포용 서명은 별도 설정 필요)

## 사용법
- 첫 화면 **롬 추가** → .nds 파일 선택 (앱 내부로 복사됨. 롬은 직접 소유한 파일만 사용하세요)
- **치트 DB** → `usercheat.dat` 선택. 게임 중 메뉴(메뉴 버튼 또는 뒤로가기) → **치트 설정**
- 게임 중 메뉴: 스테이트 저장/불러오기(슬롯 1~4), 게임 데이터(SRAM) 저장/불러오기, 배속, 소리, 리셋
- 게임을 나가거나 앱을 벗어나면 **게임 데이터 + 자동 스테이트가 자동 저장**되고, 다음 실행 때 이어서 시작됩니다
- **백업 만들기** → zip 저장 (게임 데이터·스테이트·치트 선택·usercheat.dat 포함, **롬은 미포함**)
- 새 폰: 앱 설치 → **백업 복원** → 같은 롬을 **롬 추가** → 이어하기
  (게임 식별은 파일명이 아니라 ROM 헤더(게임코드+CRC) 기준이라 파일명이 달라도 연결됩니다)

## 알아둘 점
- 스테이트(진행 상황)는 코어 버전이 다르면 호환되지 않을 수 있습니다. 그래서 **인게임 저장(SRAM)도 따로 저장**합니다 — 가장 안전한 이어하기 수단입니다.
- 이 코어는 치트를 개별로 끌 수 없어, 적용 시 목록을 비우고 선택한 것만 다시 등록합니다.
- DS 에뮬레이션은 무거워서 저사양 폰에서는 느릴 수 있습니다. 첫 화면 **성능 설정**에서 프레임 스킵을 올리면 도움이 됩니다(다음 실행부터 적용). 기본값은 정확한 타이밍 끔 + 3D 2스레드 + 롬 메모리 적재입니다.
- 치트 DB 를 불러오면 현재 롬별 인식 결과가 표시됩니다. 헤더 CRC 가 달라도 게임코드가 같으면 그 항목을 사용합니다.
- 코어 이름을 바꾸려면 `build.yml` 의 `CORE=` 와 `GameActivity.CORE_LIB` 를 함께 수정하세요.
- 라이선스: LibretroDroid(GPLv3), DeSmuME(GPLv2+) 를 사용하므로 이 앱도 소스 공개(GPL) 조건을 따라야 합니다.
